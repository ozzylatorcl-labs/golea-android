# GOLEA Android V1

APK Android de GOLEA.

## Compilación automática
Al subir este proyecto a la rama `main`, GitHub Actions compila automáticamente `GOLEA.apk` y lo publica en el release `v1.0`.

Descarga estable prevista:
`https://github.com/ozzylatorcl-labs/golea-android/releases/latest/download/GOLEA.apk`

La aplicación abre la versión web oficial de GOLEA dentro de una experiencia Android con splash, icono y navegación Atrás.
