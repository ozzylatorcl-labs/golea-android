## Instalación

1. Descarga `GOLEA.apk`.
2. Si Android lo solicita, permite instalar aplicaciones desde el navegador o gestor de archivos.
3. Abre `GOLEA.apk` y pulsa **Instalar**.
4. Abre **GOLEA** desde el menú de aplicaciones.

## Qué incluye

- Acceso directo a la web oficial de GOLEA.
- Splash de inicio.
- Icono propio.
- Navegación Android con botón Atrás.
- Compilación automática con GitHub Actions.
- Publicación automática de `GOLEA.apk` en GitHub Releases.

## Actualizaciones

Cada cambio enviado a la rama `main` vuelve a compilar la APK automáticamente. El enlace y el QR de descarga apuntan siempre a la versión más reciente.
