GOLEA Android V1
================

Paquete: cl.ozzylatorlabs.golea
Versión: 1.0 (versionCode 1)
Web: https://golea.ozzylatorcl.workers.dev/

Incluye:
- Splash GOLEA.
- Icono propio.
- WebView seguro HTTPS con JavaScript/DOM storage.
- Navegación Atrás correcta.
- Enlaces externos (noticias) se abren fuera de la app.
- Soporte launcher Android y Android TV (primera prueba).
- Workflow GitHub Actions para generar app-debug.apk sin Android Studio local.

Esta V1 reutiliza la web GOLEA responsive para validar instalación y navegación.
La siguiente fase puede sumar favoritos, notificaciones y navegación nativa por pestañas.
