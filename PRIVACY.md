# Política de Privacidad de GOLEA

**Última actualización:** 4 de septiembre de 2026

GOLEA es una aplicación desarrollada y publicada por **Ozzylator Labs**. Esta Política de Privacidad explica qué información puede tratarse al utilizar la aplicación GOLEA y el contenido web que muestra.

## 1. Funcionamiento de la aplicación

GOLEA es una aplicación Android que muestra contenido del sitio oficial de GOLEA mediante una vista web integrada (WebView). La aplicación requiere conexión a Internet para cargar resultados, noticias, estadísticas y demás contenido disponible en el servicio.

## 2. Permisos del dispositivo

La versión actual de GOLEA utiliza únicamente el permiso de acceso a Internet necesario para cargar el contenido en línea.

GOLEA no solicita acceso directo a:

- ubicación precisa o aproximada;
- cámara;
- micrófono;
- contactos;
- SMS;
- registro de llamadas;
- fotografías, videos o archivos personales del dispositivo.

## 3. Datos personales

La aplicación Android, por sí misma, no exige crear una cuenta ni solicita directamente nombre, dirección, número de teléfono u otros datos personales para poder utilizar sus funciones principales.

El contenido web cargado dentro de GOLEA puede utilizar almacenamiento web, cookies o tecnologías similares necesarias para el funcionamiento del sitio y de servicios de terceros integrados.

## 4. Servicios de terceros y publicidad

GOLEA y/o el contenido web mostrado dentro de la aplicación pueden utilizar servicios de terceros, incluidos servicios de Google relacionados con publicidad, medición, seguridad o funcionamiento del contenido.

Estos proveedores pueden procesar información técnica como dirección IP, tipo de dispositivo, identificadores, información del navegador o WebView, interacción con anuncios y datos similares de acuerdo con sus propias políticas de privacidad.

Cuando corresponda, la publicidad mostrada en GOLEA se ajustará a las políticas de Google Play y del proveedor publicitario utilizado.

## 5. Enlaces externos

GOLEA puede contener enlaces que abren sitios o servicios externos. Ozzylator Labs no controla las prácticas de privacidad de sitios de terceros. Se recomienda revisar la política de privacidad del servicio correspondiente antes de entregar información personal.

## 6. Seguridad

Ozzylator Labs aplica medidas razonables para mantener la aplicación y sus comunicaciones protegidas. La aplicación utiliza conexiones seguras HTTPS para cargar el contenido principal y no permite tráfico web inseguro en texto claro.

## 7. Menores de edad

GOLEA es una aplicación de información deportiva general y no está diseñada específicamente para recopilar datos personales de niños. No solicitamos conscientemente información personal directamente a menores mediante la aplicación Android.

## 8. Conservación y eliminación de datos

La aplicación Android no mantiene una base de datos propia de cuentas de usuario ni almacena directamente datos personales identificables del usuario en servidores propios como requisito para su uso.

Si en el futuro se incorporan cuentas, formularios u otras funciones que impliquen tratamiento adicional de datos personales, esta Política de Privacidad se actualizará y se habilitarán los mecanismos correspondientes para gestionar o solicitar la eliminación de dichos datos.

## 9. Cambios en esta Política de Privacidad

Esta política puede actualizarse cuando cambien las funciones de GOLEA, los servicios integrados o los requisitos legales y de Google Play. La versión vigente estará disponible públicamente en esta página.
